# Настройка Sanity CMS для Yogamoon

## Шаг 1 — Установить пакеты

В терминале, в папке проекта (`C:\Repositories\yogamoon`):

```bash
npm install sanity @sanity/client next-sanity @sanity/image-url
```

Дождитесь завершения (1–2 минуты).

---

## Шаг 2 — Создать проект на sanity.io

1. Перейди на [sanity.io](https://sanity.io) и войди (или зарегистрируйся через Google).
2. Нажми **"Create new project"**.
3. Название проекта: `Yogamoon` (или любое другое).
4. Dataset: оставь `production`.
5. После создания скопируй **Project ID** — выглядит как `abc12def`.

---

## Шаг 3 — Добавить Project ID в .env.local

Открой файл `.env.local` в корне проекта и замени `ВАШ_PROJECT_ID` на свой реальный ID:

```
NEXT_PUBLIC_SANITY_PROJECT_ID=abc12def
NEXT_PUBLIC_SANITY_DATASET=production
```

---

## Шаг 4 — Запустить сайт

```bash
npm run dev
```

Открой в браузере:
- **Сайт**: http://localhost:3000
- **Студия CMS**: http://localhost:3000/studio

---

## Шаг 5 — Добавить себя как редактора в Sanity

На [sanity.io/manage](https://sanity.io/manage) → выбери проект Yogamoon → вкладка **Members** → добавь свой email с ролью **Editor**, если планируешь входить в студию с другого аккаунта.

---

## Шаг 6 — Заполнить контент в Studio

Открой http://localhost:3000/studio. В левом меню увидишь разделы:

### Настройки сайта *(заполни первым)*
Здесь хранятся глобальные данные: название сайта, телефон, ссылки на соцсети.

| Поле | Пример |
|------|--------|
| Название сайта | Yogamoon |
| WhatsApp номер | 972512060874 |
| Телефон | +972-51-206-0874 |
| Telegram | @irenyarovaya |
| Instagram | @irina_yogamoon |
| Facebook | Irina_yoga_israel |
| Адрес студии | Раанана, парк «Экологи», Ход аШарон |

### Контактная секция
Данные для раздела «Записаться на занятие». Заголовок, описание, контакты и адрес.

### Слайды Hero
Три слайда главного экрана. **Порядок: 1, 2, 3.**

Для каждого слайда:
- **Изображение для ПК** (desktop) — загрузи фото
- **Изображение для мобильных** — можно то же или отдельное в вертикальной обрезке
- Заголовок, подзаголовок, метка
- Кнопки (текст + ссылка)
- Пункты тела (bodyItems) — список параграфов или принципов

> Если слайды не заполнены, сайт автоматически показывает стандартный контент.

### Форматы занятий (Услуги)
Пять карточек с описанием форматов. **Порядок: 1–5.**

| Поле | Пример |
|------|--------|
| Название | Групповая хатха-йога |
| Описание | Занятия в студии Раананы... |
| Тег | Офлайн · Раанана |
| Иконка | Загрузи изображение |

### Цены (Группы прайс-листа)
Три группы карточек: групповые, индивидуальные, онлайн-клуб. **Порядок: 1, 2, 3.**

Для каждой группы добавь карточки. Карточки клуба должны содержать список **Особенности** (features) — тогда они отобразятся в клубном стиле.

Флаги:
- **Популярный** — выделяет карточку фиолетовым по умолчанию
- **Лучший выбор** — то же для клубных карточек

### Отзывы
Каждый отзыв: имя, мета (тип занятий · стаж), текст, оценка (1–5), фото (необязательно).

## Деплой на Vercel (когда будешь готова)

1. Залей проект на GitHub.
2. На [vercel.com](https://vercel.com) создай новый проект из этого репозитория.
3. В настройках проекта на Vercel добавь переменные окружения:
   - `NEXT_PUBLIC_SANITY_PROJECT_ID` = твой Project ID
   - `NEXT_PUBLIC_SANITY_DATASET` = `production`
4. В [sanity.io/manage](https://sanity.io/manage) → проект → вкладка **API** → добавь `https://твой-домен.vercel.app` в **CORS Origins** (с галочкой «Allow credentials»).
5. Также добавь домен в **Allowed Studio Hosts**, чтобы студия работала по адресу `https://твой-домен.vercel.app/studio`.

---

## Что происходит, если Sanity не настроен

Сайт полностью работает без CMS — показывает встроенный контент. Sanity данные подключаются только когда `NEXT_PUBLIC_SANITY_PROJECT_ID` содержит реальный ID.
