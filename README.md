# Yogamoon

Одностраничный сайт преподавателя йоги Ирины Лындиной. Проект построен на
Next.js App Router, React и TypeScript.

## Локальный запуск

Требуется актуальная LTS-версия Node.js.

```bash
npm ci
npm run dev
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
```

Production-сборка включает проверку TypeScript и генерацию статической страницы.
Все проверки подряд можно запустить командой `npm run check`.

## Структура

```text
app/                    маршруты, metadata и глобальные стили
src/components/         секции страницы и интерактивные компоненты
public/                 изображения, иконки и сертификаты
scripts/                служебные скрипты синхронизации с Figma
styles/                 экспортированные дизайн-токены
```

## Контактная форма

Сейчас форма использует временную клиентскую заглушку и не отправляет данные.
Перед публикацией необходимо подключить согласованный с владельцем сайта канал
отправки и добавить серверную валидацию, обработку ошибок и защиту от спама.

## Figma

Для синхронизации предусмотрена команда:

```bash
npm run figma:sync
```

Скрипту могут потребоваться значения из `.env.local`. Секреты нельзя добавлять
в репозиторий или размещать в клиентском коде.

## Перед публикацией

- подключить реальную отправку контактной формы;
- проверить телефон, адрес и ссылки на социальные сети с владельцем сайта;
- проверить цены и тексты;
- выполнить `npm run lint` и `npm run build`;
- проверить страницу на мобильном устройстве владельца сайта.
